# SmallNoise

Запуск: `node server.js`. На http://127.0.0.1:5173 можно выбрать студию. Установка зависимостей не требуется.

- `/music/` (`music/`) — SmallMusic, музыкальная студия с собственной моделью проекта и ключом автосохранения `smallmusic-project`.
- `/sounds/` (`sounds/`) — SmallSound, студия коротких синтезированных эффектов с отдельной историей.
- `shared/sound-settings.js` нормализует параметры инструментов. `shared/audio.js` воспроизводит музыкальные голоса и кодирует WAV для обеих студий.

## SmallSound

Выберите пресет или задайте пару материалов. Каталог включает 212 пресетов в семи категориях, в том числе 105 сочетаний 14 материалов. При выборе пресета и по кнопке «Новый вариант» создаётся случайная версия. Режимы «Обычный» и «8-битный» доступны для каждого эффекта.

Настройте звук ползунками и прослушайте результат. Каждый сгенерированный вариант попадает в историю автоматически. «Сохранить правки в историю» добавляет отредактированную версию отдельной записью. История, избранное и текущий черновик сохраняются в браузере. Экспорт скачивает текущую версию в WAV или AIFF, моно PCM 16 бит, 44,1 кГц.

## SmallMusic

1. Выберите один из 16 готовых инструментов в каталоге и нажмите ＋.
2. Создайте именованный паттерн. Инструмент задаёт исходный тембр. Через «Звучание» настраиваются громкость, панорама, строй, три дополнительных осциллятора, огибающая, фильтр, LFO, насыщение и эхо. Прослушайте черновик на клавишах панели и нажмите «Применить». Настройки сохраняются вместе с нотами и действуют на все экземпляры паттерна.
3. Клик в пианоролле добавляет ноту. Перетаскивание меняет позицию и высоту; правый край — длительность. Выбранную ноту можно настроить числами внизу. Правый клик удаляет ноту.
4. «Копия» создаёт независимый паттерн с тем же инструментом. Кнопки −½ / +½ сдвигают все ноты на один полутон.
5. Перетащите паттерн из библиотеки на линию, дважды кликните по сетке или нажмите «На линию». Все блоки с одним patternId используют общий паттерн. Правки нот, длины и имени отражаются во всех экземплярах.
6. Перемещайте блоки. Потяните правый край, чтобы повторить или обрезать паттерн. Alt + перетаскивание создаёт ещё один связанный экземпляр. Правый клик удаляет блок. Линии не закреплены за инструментом.
7. Пробел воспроизводит трек. «▷ Паттерн» прослушивает выбранную партию отдельно. M/S и громкость работают для линии.
8. «Экспорт WAV» рендерит всю аранжировку в стерео WAV 44.1 kHz. «Сохранить» скачивает проект JSON, а «Открыть» восстанавливает его. Автосохранение действует в текущем браузере. Старые проекты получают нейтральные параметры звучания при загрузке.

Каталог, аранжировка и пианоролл прокручиваются отдельно. Нет вступительного экрана. Ctrl+Z отменяет редактирование, включая удаление паттерна и создание нового проекта. A–K — экранная игра на выбранном инструменте.

Звуки — встроенные синтезированные пресеты с неизменяемыми настройками, а не записи реальных гитар или флейт. VST, внешние MIDI-устройства и импорт аудиосэмплов пока не поддерживаются. Диапазон редактора C3–B6. Число линий и паттернов не имеет искусственного ограничения; практический предел зависит от памяти браузера.

Проверки доступны через `npm run check` или `node --test model.test.js sounds/engine.test.js`.
