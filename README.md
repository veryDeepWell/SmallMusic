# SmallMusic

Браузерная музыкальная студия на одном экране. Запуск: `node server.js`, затем открыть http://127.0.0.1:5173.

Без установки зависимостей. Звук генерируется через Web Audio API. Есть демопроект, пианоролл, повторяемые паттерны, mute/solo, автосохранение и WAV-экспорт.

- Пробел — воспроизведение / стоп; A–K — игра на клавиатуре.
- Двойной клик по аранжировке — добавить паттерн; перемещение мышью — перенести; правый край — изменить длину повтора.
- Alt + перетаскивание — копировать паттерн; правый клик — удалить.
- Двойной клик в пианоролле — добавить ноту; правый клик — удалить. Ноты перемещаются, правый край меняет длительность.
- Ctrl+Z — отменить редактирование.
- Проект автоматически сохраняется в текущем браузере. «Сохранить» скачивает JSON-копию, «Экспорт» — WAV 44.1 kHz.

Это первая рабочая версия: встроенные синтезаторы, без VST, записи микрофона и импорта сэмплов.
